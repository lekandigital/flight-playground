## Pack-builder corrections for the next batch

| Area | Wrong or missing fact | Builder change |
| --- | --- | --- |
| Conditions and object identity | Boolean operators, source instances and logical group membership were lost. Heuristic categories include structural parts, doors and instrument dials. | Preserve condition AST, XML instance path, full group descendants and exact object bindings. Use category guesses as advisory metadata. |
| Animation hierarchy | Pivot ancestors/descendants are duplicated; channel labels mix external controls, cockpit motion, trim, compression and spin. E-Flash expression matching confused two property-less animations. | Export ordered/nested transformations, source animation ordinals, expression AST and driving property domains. |
| Contacts | “Trusted” sometimes means only point-to-AABB proximity. F4U belly contacts, fixed helicopter skids and E-Flash tyres are misclassified. BO pitch includes an auxiliary tail point. | Identify contact purpose and solver state; validate against actual tyre/skid vertices; fit parked pitch only to active primary contacts. Keep water contacts distinct. |
| Dimensions and variant | F4U-4 versus F4U-1, F-16C versus YF, BO CB versus CBS and mixed EC130 variants. Height depends on gear pose and rotor/prop phase. | Record exact selected set/variant, measurement pose, visible-part mask and rotating-part phase; flag mismatches rather than rescaling to a different variant. |
| Rotor/propeller facts | Chord, mechanical incidence limits, cyclic azimuth, `phi0`, spin sign and per-propeller blade counts are absent or flattened. Numeric-string `ccw` needs parsing. | Retain full YASim parameters and distinguish visual hub from thrust point. Do not fabricate RPM where the source supplies none. |
| Normalized travel and units | F-16 radians were treated as normalized travel; S.6B/M.C.72 normalized controls were null. E-Flash span is 34.61 ft, not metres. | Preserve property units, interpolation domain, controller gain/bias and mechanical range separately. |
| Textures and liveries | 400-row truncation loses bindings; external reflection/light maps are counted as missing paint. F-16 livery slots and selected YF schemes were omitted. Some meshes lost UVs. | Export uncapped instance-specific paint slots and filename aliases; distinguish paint, reflection, light and missing UV. Copy only files used by exported meshes/liveries. |
| Source completeness | Missing F-16 main/base XML, helicopter base includes, M.33 set include and S.6B/M.C.72 base systems leave startup aliases unresolved. BO orange rotor/emblem and E-Flash instrument maps are absent. | Report dependency closure and archive absence explicitly. Include startup alias definitions or mark their values unknown. |
| References and alternates | Spitfire/Seafire splash is IIa; F4U alternate is A-7E; Dauphin alternate is DR400; several photos show unrelated objects or variants. Ca.60 drawing11 is solid black and its Noviplano alternate GLB has no meshes. | Match aircraft/variant before ranking, verify downloaded image content and identify donor provenance without inventing licence metadata. |
| Static/manual models | Ca.60 has no FlightGear XML; generic animation instructions and blanket four-blade metadata are inappropriate. Conflicting period/museum/pack dimensions lack a source hierarchy. | Mark XML/FDM fields inapplicable; provide dimensioned evidence, per-engine layout and source-qualified dimensions. |
